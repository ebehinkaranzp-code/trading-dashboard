# آرشیو داده تاریخی بک‌تست BTCUSDT

این پوشه برای داده‌های تاریخی **Binance Spot BTCUSDT، تایم‌فریم ۱ دقیقه** در نظر گرفته شده است. داده خام از آرشیو رسمی Binance Vision دریافت می‌شود و برای ساخت تایم‌فریم‌های بالاتر (۳m تا ماهانه) مناسب است.

## دریافت داده

از ریشه پروژه اجرا کنید:

```bash
python scripts/download_binance_btcusdt_history.py
```

بازه پیش‌فرض از ۲۰۱۷-۰۸-۱۷ تا آخرین روز کامل UTC است. برای تعیین بازه:

```bash
python scripts/download_binance_btcusdt_history.py --start 2017-08-17 --end 2026-11-15
```

فایل‌های ماهانه رسمی برای ماه‌های کامل و فایل‌های روزانه برای ماه جاری دریافت می‌شوند. در صورت وجود فایل CHECKSUM، صحت SHA256 بررسی می‌شود. فایل‌های CSV استخراج‌شده در `data/backtest/binance/BTCUSDT/1m/csv/` و فهرست دریافت در `manifest.json` ذخیره می‌شود.

## نکته مهم داده

از ۱ ژانویه ۲۰۲۵، timestamp کندل‌های Spot در آرشیو Binance از میکروثانیه استفاده می‌کند؛ پیش از آن میلی‌ثانیه است. هنگام خواندن CSV باید این تغییر واحد لحاظ شود. فایل‌های خام دست‌نخورده نگه داشته می‌شوند.

## منبع و اعتبار

- آرشیو رسمی: https://data.binance.vision/
- راهنمای رسمی و ساختار فایل‌ها: https://github.com/binance/binance-public-data
- داده‌ها هنوز داخل این بسته دانلود نشده‌اند؛ این بسته اسکریپت دریافت، استخراج، بررسی checksum و manifest را اضافه می‌کند. پس از اجرای اسکریپت، داده‌های واقعی در مسیر فوق قرار می‌گیرند.
