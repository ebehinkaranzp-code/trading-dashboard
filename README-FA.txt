Trading Dashboard v2.8.1

قابلیت‌ها:
- داشبورد بازار چندصرافی، نمودار، اندیکاتورها، Order Flow و مشتقات.
- آرشیو/کش محلی و نمایش داده ذخیره‌شده در حالت آفلاین.
- پایش مستقل سه مسیر سیگنال:
  1) Quattro Donchian v2 — BTC / 4H
  2) Momentum + Volatility Targeting — BTC / 1D
  3) Momentum + Volatility Targeting — ETH / 1D
- هشدار ورود، ورود اجراشده، افزودن پله، خروج و تغییر تخصیص.
- تاریخچه رویدادها، جلوگیری از هشدار تکراری و تشخیص داده کهنه.
- انتخاب پارامتر Momentum با Walk-forward (آموزش ۳ ساله، آزمون ۱۸۲ روزه).

نصب در GitHub Pages:
1. ZIP را استخراج کن.
2. وارد پوشه trading-dashboard-main شو.
3. تمام محتویات داخل آن (از جمله index.html، modules، data، .github و فایل‌های html) را در ریشه مخزن GitHub آپلود کن؛ خود پوشه را به‌عنوان زیرپوشه سایت قرار نده.
4. ساختار پوشه‌ها را حفظ کن و commit/push انجام بده.
5. سایت را با HTTPS باز کن، وارد «استراتژی‌ها و سیگنال‌ها» شو و مجوز اعلان مرورگر را فعال کن.

نکته هشدار:
اعلان مرورگر فقط تا وقتی صفحه داشبورد باز است کار می‌کند. برای هشدار حتی وقتی سایت بسته است، سرور Push و Backend مستقل لازم است.

محدودیت و ایمنی:
- هیچ سفارش واقعی ارسال نمی‌شود.
- Quattro فقط BTC/4H است؛ Momentum فقط BTC و ETH/1D.
- در بازسازی وضعیت Quattro کارمزد taker لحاظ شده اما funding و slippage زنده در سیگنال لحاظ نشده‌اند.
- آرشیو BTC/ETH از Coin Metrics Community با مجوز CC BY-NC 4.0 است؛ برای استفاده تجاری مجوز جداگانه لازم است.
- نتیجه تاریخی تضمین عملکرد آینده نیست.
