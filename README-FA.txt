بسته اصلاح داشبورد معاملاتی

محتویات:
1) footprint.html
   نسخه اصلاح‌شده صفحه Footprint.
   - هنگام ورود به صفحه، خودش بارگذاری را آغاز می‌کند.
   - اگر تاریخ انتخاب‌شده فایل نداشته باشد، تا ۷ روز اخیر را برای آخرین آرشیو موجود بررسی می‌کند.
   - پیام خطا و وضعیت را واضح‌تر نشان می‌دهد.
   - ظاهر کنترل‌ها و لینک بازگشت کوچک‌تر شده و در موبایل بهتر جا می‌گیرد.
   - تأکید می‌کند که داده آرشیوشده ممکن است پوشش کامل معاملات را نداشته باشد.

2) index-header-patch.txt
   تغییرات کوچک‌کردن لینک‌های بالای صفحه اصلی. دو قانون CSS را طبق راهنما جایگزین و قانون موبایل را اضافه کنید.

روش نصب:
- قبل از جایگزینی، از footprint.html فعلی یک کپی پشتیبان بگیرید.
- فایل footprint.html این بسته را در ریشه مخزن GitHub، کنار index.html، بارگذاری و فایل قبلی را جایگزین کنید.
- سپس تغییرات CSS داخل index-header-patch.txt را در index.html اعمال کنید.
- هیچ فایل داده، Workflow، منطق سیگنال یا تاریخچه‌ای در این بسته تغییر نکرده است.

محدودیت:
این بسته روی نسخه عمومی فعلی مخزن بررسی شده است. به دلیل در دسترس نبودن ZIP آپلودشده در این نوبت، فایل کامل index.html را بازنویسی نکرده‌ام تا هیچ‌کدام از قابلیت‌های فعلی ناخواسته حذف نشوند. فقط Patch دقیق CSS ارائه شده است.
