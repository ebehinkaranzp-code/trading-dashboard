ورود فایل تکی یا پروژه کامل، آزمایش محلی، بازبینی و انتشار با تأیید نهایی

۱) افزودن تغییرات

آپلود پروژه کامل یا چند فایل
فایل ZIP پروژه را یکجا بده؛ یا چند فایل را هم‌زمان انتخاب کن. مسیر پوشه‌ها حفظ می‌شود.

دریافت از بعضی سایت‌ها به‌دلیل محدودیت CORS ممکن نیست؛ در این حالت فایل را دانلود و از بخش آپلود وارد کن.

۲) ورود مستقیم متن یا کد

هنوز فایلی وارد نشده است.

فایل‌ها در فضای محلی همین مرورگر نگهداری می‌شوند و با بستن صفحه از بین نمی‌روند. پاک‌کردن داده‌های مرورگر ممکن است آن‌ها را حذف کند.

۳) فهرست فایل‌ها و ویرایش

فایلی وارد نشده است.

۴) آزمایش و بازبینی

ابتدا فایل‌ها را وارد کن و «بررسی فایل‌ها» را بزن.

این پیش‌نمایش در محیط ایزوله مرورگر باز می‌شود. فایل‌های وابسته با مسیر نسبی ممکن است در این پیش‌نمایش بارگذاری نشوند؛ برای تست کامل پروژه، بسته ZIP را در محیط محلی وب‌سرور اجرا کن.

• کد JavaScript فقط از نظر Syntax بررسی می‌شود و در این صفحه اجرا نمی‌شود.
• JSON از نظر ساختار تجزیه می‌شود.
• فایل اصلی سایت تا زمان انتشار تغییر نمی‌کند.
• انتشار آنلاین فقط بعد از تأیید صریح انجام می‌شود.

۵) انتشار آنلاین با تأیید تو

برای انتشار امن، یک واسط سمت سرور (مثلاً Cloudflare Worker) لازم است. کلید GitHub نباید در این صفحه یا فایل‌های عمومی سایت قرار بگیرد.

انتشار آنلاین تا زمان نصب و تنظیم سرویس امن غیرفعال است.

این فایل به‌تنهایی توکن GitHub را دریافت یا ذخیره نمی‌کند. بعد از آماده‌شدن Worker، آدرس آن را اینجا وارد می‌کنی.
